## 🧪 Other experiments

| Project | What it does |
|---|---|
| [**omp-pi-install**](https://github.com/rayoplateado/omp-pi-install) | Installs Pi plugins in Oh My Pi, remapping imports automatically. |
| [**noctalia-codex-usage**](https://github.com/rayoplateado/noctalia-codex-usage) | Noctalia plugin that shows your OpenAI Codex usage limits. |
